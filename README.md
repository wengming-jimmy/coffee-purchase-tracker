# 咖啡店每日進貨紀錄

石牌店、士林店每日進貨紀錄的 RWD 單檔網頁，手機、電腦都能用。

## 使用方式

1. 開啟 `index.html`（或 GitHub Pages 網址）。
2. 上方切換石牌店、士林店。
3. 輸入日期、品名、數量、單價，金額自動計算，單位可不填。
4. 選月份查看本月筆數、分店總金額、兩店合計與品名小計。
5. 月底按「匯出 CSV」，再拿去跟 POS 合併。
6. 後台管理：按「開啟後台」，可用品名或日期搜尋、分店篩選，勾選有問題的資料列後一次刪除；刪除前建議先按「匯出全部備份 CSV」備份，刪除後無法復原。

CSV 欄位順序：日期,分店,品名,單位,數量,單價,金額。

## 注意事項

第一版資料只存在使用裝置的瀏覽器 localStorage，換裝置或清除瀏覽資料會不見。
正式給兩店共用前，請先匯出備份，或升級成共用雲端版本。
